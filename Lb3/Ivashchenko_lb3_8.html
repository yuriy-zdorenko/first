СУ чому різниця між UI та UX дизайном?

Цифровий журнал від Іващенко Анастасії

UX Дизайн

UX це про зручність та логіку. Головне завдання UX-дизайнера — зробити взаємодію з сайтом чи застосунком максимально простою та зрозумілою для користувача.

На цьому етапі вивчають потреби аудиторії, продумують, як людина буде рухатися від першого кліку до наступних.

UI Дизайн

UI це про зовнішній вигляд та естетику. Завдання UI-дизайнера — створити привабливий візуальний стиль цифрового продукту.

На цьому етапі підбирають колірну палітру, шрифти, відступи, вигляд кнопок, іконок та анімації. UI робить продукт візуально приємним.
