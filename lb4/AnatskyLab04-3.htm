YouTube — найбільший відеохостинг, де можна переглядати та завантажувати відео.
Wikipedia
Wikipedia — вільна енциклопедія, яку може редагувати кожен охочий.
Facebook
Facebook — одна з найбільших соціальних мереж світу.
Instagram
Instagram — соціальна мережа для обміну фотографіями та відео.
Microsoft
Microsoft — компанія-розробник операційної системи Windows та офісних програм.

Нова пошта — популярна українська служба доставки посилок.
