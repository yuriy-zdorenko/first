Глобальні таблиці стилів

Розділ 1. Що таке CSS

CSS (Cascading Style Sheets) — це мова опису зовнішнього вигляду документа, написаного мовою розмітки HTML. Вона дозволяє відокремити зміст документа від його оформлення, що робить код чистішим і зручнішим для підтримки.

За допомогою CSS можна керувати шрифтами, кольорами, відступами, рамками, фоном та багатьма іншими властивостями елементів.

Розділ 2. Способи підключення стилів

Існує чотири основні способи підключення стилів до HTML-документа:

  • Внутрішні (inline) — через атрибут style;
  • Глобальні — через тег <style> у <head>;
  • Зовнішні (linked) — через тег <link>;
  • Імпортовані — через @import.

Розділ 3. Переваги глобальних стилів

Глобальні таблиці стилів дозволяють задати єдине оформлення для всіх елементів певного типу в документі. Це значно скорочує код і спрощує подальшу зміну дизайну сторінки.

Достатньо змінити одне правило в <style>, щоб оновити вигляд усіх відповідних елементів на сторінці.

Детальніше про CSS можна дізнатися на W3Schools.
