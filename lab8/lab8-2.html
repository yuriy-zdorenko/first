Завдання 2. Забезпечення єдності стилю через тег <style>

Розділ 1. Принцип дії глобальних стилів

Глобальні таблиці стилів оголошуються в заголовочній секції <head> HTML-документа за допомогою тега <style>. Це дозволяє централізовано керувати зовнішнім виглядом усіх однотипних тегів на сторінці.

Зміна одного значення у селекторі автоматично оновлює відображення елементів у всіх абзацах та блоках документа, що значно скорочує розмір файлу та спрощує розробку.

Розділ 2. Застосування контейнерів <div> та <p>

Контейнери <div> використовуються для групування елементів сторінки у логічні блоки та модулі. Завдяки CSS можна легко налаштувати внутрішні відступи (padding), зовнішні поля (margin), кольори фону та рамки для кожного блоку.

Завдяки єдиному правилу форматування абзаців p { text-indent: 2em; text-align: justify; } весь текст на сторінці має акуратний вигляд із дотриманням типографічних норм.
