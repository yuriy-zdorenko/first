Моє хобі

Одне з моїх захоплень — створенням вебсторінок. Мені подобається бачити, як звичайний текстовий код перетворюється на сторінку, яку можна відкрити у браузері. Це дає змогу експериментувати з оформленням, структурою та поведінкою елементів.

Під час роботи над вебсторінками я можу змінювати кольори, шрифти, розташування тексту та інші деталі. Програмування розвиває уважність і терпіння, оскільки навіть невелика помилка в коді може вплинути на результат. Мені цікаво вчитися на таких прикладах і поступово робити свої роботи кращими.

Програмування

Нижче наведено невелику програму мовою Python. Вона запитує ім’я користувача та виводить привітання. 

#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    cout << "Як тебе звати? ";
    getline(cin, name);

    if (!name.empty()) {
        cout << "Привіт, " << name << "!" << endl;
    } else {
        cout << "Привіт!" << endl;
    }

    return 0;
}
