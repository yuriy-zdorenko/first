Програмування

Приклад невеликої програми мовою C++, яка виводить таблицю множення на 3:

#include <iostream>
using namespace std;

int main()
{
    for (int i = 1; i <= 5; i++)
    {
        cout << "3 x " << i << " = " << 3 * i << endl;
    }
    return 0;
}
