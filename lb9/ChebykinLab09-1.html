Приклади програм для стилізації робочого столу на Windows

Rainmetr

Безкоштовна і дуже гнучка програма для створення та встановлення «віджетів» на робочому столі: годинник, системні лічильники, погода, RSS-стрічки тощо.

Wallpaper Engine

Одна з найпопулярніших програм для живих шпалер на Windows. Підтримує анімації, відео, 3D-сцени, інтерактивні ефекти та дозволяє створювати власні шпалери за допомогою редактора.

Live Walpapper

Безкоштовна та відкрита альтернатива Wallpaper Engine. Дозволяє ставити відео, GIF, веб-сторінки та анімації як шпалери, має низьке споживання ресурсів та добре оптимізована для слабких ПК.

WindowBlinds

Дозволяє змінювати тему інтерфейсу Windows — рамки вікон, кольори, шрифти, кнопки, загальний стиль ОС.

DeskScapes

Якщо хочеш живі шпалери або анімований фон робочого столу, ця програма дає таку можливість.

Winstep Xtreme

Пакет для зміни інтерфейсу Windows, який включає серед іншого док-панель, віджети, альтернативне меню «Пуск» тощо.
