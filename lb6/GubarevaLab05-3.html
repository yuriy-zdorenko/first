Мої гіперпосилання

Google
Google - один із популярних в Україні пошукових серверів
Duolingo
Duolingo - популярний безкоштовний сервіс для вивчення іноземних мов у формі гри.
Портал Дія
Портал Дія - український державний вебпортал електронних послуг.
Canva
Canva - простий та інтуїтивний онлайн-конструктор для створення графічного дизайну
GitHub
GitHub - найбільша у світі платформа для хостингу IT-проєктів та спільної роботи над кодом.
Rozetka
Rozetka - найвідоміший та найбільший український інтернет-магазин і маркетплейс.
GeoGuessr
GeoGuessr - захоплива географічна онлайн-гра, яка закидає вас у випадкову точку світу на Google Maps, а ви маєте вгадати, де перебуваєте.
