Екосистема Google

Основні додатки та сервіси

Google Search
Пошукова система для знаходження інформації в мережі Інтернет.
Google Drive
Хмарне сховище даних для зберігання файлів та синхронізації їх між пристроями.
Gmail
Безплатний сервіс електронної пошти від компанії Google.
Google Docs
Хмарний текстовий редактор для створення та спільного редагування документів.
Google Sheets
Інструмент для роботи з електронними таблицями в режимі онлайн.
Google Calendar
Сервіс-органайзер для планування подій, зустрічей та нагадувань.
Google Maps
Картографічний сервіс із можливістю побудови маршрутів та перегляду панорам.
YouTube
Відеохостинг для перегляду, публікації та трансляції відеоматеріалів.
